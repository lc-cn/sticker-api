# fonts/

Renderer-provided fonts for A light-v1 templates (template `fonts[].providedBy = "renderer"`).
No font is committed yet. Before enabling text renders, add a font whose licence allows
redistribution (e.g. Noto Sans SC / Source Han Sans, SIL OFL 1.1), record its file SHA-256 and
the OFL text in fonts/NOTICE, and set `RENDER_FONTS=default-sans=<Family Name>@fonts/<file>`.
