小智表情包
表情 制图 API

API 文档

完整定义见 openapi.yaml（OpenAPI 3），可以导入 Swagger Editor、Postman 等工具查看。

公开接口（无需登录）

接口说明
GET /v1/assets?q=&category=&tag=&limit=&cursor=搜索表情，返回 items[].sources（镜像链接，按优先级排列）和 nextCursor。
GET /v1/assets/{id}单张表情详情。
GET /v1/assets/{id}/content302 跳到图片（首选镜像）。
GET /v1/categories分类列表与数量。
GET /v1/templates梗图模板，含输入要求和缩略图 preview。
POST /v1/renders生成梗图，返回 PNG。带令牌调用，或在开放访客制图时匿名调用（按 IP 限流）。
GET /v1/health服务状态。

示例

curl 'https://sticker.l2cl.link/v1/assets?q=哈哈&limit=10'

curl -X POST https://sticker.l2cl.link/v1/renders \
  -H 'content-type: application/json' \
  -d '{"template":"good-news","texts":["今天不加班"]}' -o good-news.png

# 需要图片的模板：multipart，字段 request（JSON）+ image（文件，单张 ≤1MB）
curl -X POST https://sticker.l2cl.link/v1/renders \
  -F 'request={"template":"need"}' -F 'image=@me.png' -o need.png

限制

匿名制图按客户端 IP 限流（默认每分钟 6 次、每天 100 次），超出返回 429 和 Retry-After。计数在每个服务实例内存中，不是全局精确配额。机器调用请使用令牌。
