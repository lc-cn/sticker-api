小智表情包
表情 制图 API

API（给 AI tool 用）

字段尽量短，列表不含镜像 sources。机器可读：tool.schema.json · openapi.yaml

公开读接口

接口说明
GET /v1/assets?q=&category=&tag=&limit=&cursor=搜索。返回 {n,next?,items:[{id,url,title,tags?,cats?,…}]}。id 为 12 位 hex，url 为短链。
GET /v1/assets/{id}详情（仍无 sources）。
GET /v1/asset/{id}.{ext}图片短链，302 到镜像。
GET /v1/categories分类与数量。
GET /v1/templates可渲染模板；preview 为短路径。
POST /v1/renders生成梗图，直接返回 PNG 字节。
GET /v1/health服务状态。

示例

curl 'https://sticker.l2cl.link/v1/assets?q=负鼠&limit=5'
# → {"n":31,"next":"…","items":[{"id":"22222f8823ed","url":"/v1/asset/22222f8823ed.png","title":"…","tags":["…"]}]}

curl -L 'https://sticker.l2cl.link/v1/asset/22222f8823ed.png' -o sticker.png

curl -X POST https://sticker.l2cl.link/v1/renders \
  -H 'content-type: application/json' \
  -d '{"template":"good-news","texts":["今天不加班"]}' -o good-news.png

限制

匿名制图按 IP 限流（默认每分钟 6 次、每天 100 次），超出 429。sources / 许可长文不在 JSON 里，见素材仓库 licenses/。
